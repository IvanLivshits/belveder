# Backlog (вне MVP)

Одна строка на идею: что, зачем, точка расширения в коде. Не делать, пока MVP не закрыт.

- Платежи Stars — монетизация; точка: отдельный пакет `payments`, бот.
- Энергия — ограничение забегов в сутки; точка: качество `profile.energy` + `rules`.
- Коллекционки и концовки — `profile`-качества уже допускают; нужен экран коллекции в ui-kit.
- Итоговый рассказ из отчётов — `engine/report.ts` уже собирает слоты, нужен шаблон «рассказа».
- UGC/редактор миров — схема в `content-schema` самодостаточна; нужен загрузчик чужого `world.json`.
- Своя БД и проверка `initData` — когда появится сервер, см. скилл `telegram-miniapp`.
- Аналитика, локализация, звук.
- Защита от рваной записи чанков сохранения — сейчас многочанковый документ может остаться наполовину записанным, если Mini App закрыли посреди записи; точка: `apps/miniapp/src/storage.ts` (`saveDoc`/`loadDoc`). План: каждый чанк несёт `rev`; заголовочный ключ с `rev` и числом чанков пишется последним; при чтении, если `rev` любого чанка не совпадает с заголовком, копия считается битой и берётся другая сторона (локальная или облачная). Тест: обрыв записи после 2 из 3 чанков → загружается другая копия.
- Рассвет по библии отнимает последнюю найденную улику; точка: эффект на перехват или `pledge_dawn`.
- При поимке (`suspicion >= 10`) залог выбирает Владелец, а не игрок; точка: `layout: pledge` с автоматическим выбором пары.
- `OR` в условиях: пара `voice` по библии — «должок Руби 2 или запись эфира Беннета»; точка: `expressions.ts` и `evaluateAll`.
- Голос Уолтера во фрагментах отчёта при `memories_returned >= 4`.
- Время вместо номера хода в HUD: `22:00 + turn × 30 мин` через `rules.clock: { quality, start, step }`; сейчас часы — качество из `rules.onChoice` (`clockQuality`), точка: `engine/cost.ts` и `QualityBar`.
