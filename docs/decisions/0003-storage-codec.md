# ADR 0003. Компактный кодек сохранений с чанками

**Статус:** принято, 2026-11-01.

**Контекст.** Telegram CloudStorage: ≤ 4096 символов на значение, ≤ 1024 ключа. Профиль с сотнями `visited.*` в JSON не влезает в одно значение.

**Решение.** Текстовый формат `b<ver>;q.<id>=<n>;…` только с ненулевыми качествами, разбиение на чанки по 4000 символов, заголовок `<ver>:<count>|` в нулевом чанке. Кодек в `engine/storage.ts`, транспорт в приложении.

**Почему.** Кодек тестируется без браузера (тест на 1500 качеств), версия схемы даёт место для миграций, ключи `profile_N`/`run_N` занимают единицы из 1024.

**Последствия.** Короткие ключи = id качеств как есть (они уже snake_case). Индексные алиасы отвергнуты: ломаются при перестановке качеств в `world.yaml`.
