# ADR 0002. Правила ночи живут в контенте, а не в движке

**Статус:** принято, 2026-11-01.

**Контекст.** Ход ночи, лимит 16 ходов, счётчик ночей — ядро игры, но и это знание о мире.

**Решение.** `world.rules`: `start`, `onChoice` (эффекты на каждый не-`free` выбор), `interrupts` (`{when, goto}`, первый подходящий после каждого выбора), `onNightEnd` (эффекты на профиль). Движок исполняет их вслепую. Конец ночи — только `endNight`-выбор или залог воспоминания: по библии из башни нельзя уйти без залога, поэтому `nightEndWhen` убран, а рассвет и поимка стали перехватами в локацию залога.

**Почему.** Движок не содержит ни одного имени качества, другой мир может иметь другие правила (энергия вместо ходов). Validator проверяет, что правила ссылаются на объявленные качества.

**Последствия.** Экран трёх дверей, этажи, «залог» — тоже контент (`layout: doors`, качество `floor`, сторилет в локации `exit`).
