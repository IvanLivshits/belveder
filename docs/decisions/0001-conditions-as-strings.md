# ADR 0001. Условия и эффекты — строки, а не структуры

**Статус:** принято, 2026-11-01.

**Контекст.** Условия (`turn >= 16`) и эффекты (`clues += 1`) можно хранить в JSON как объекты `{q, op, v}` или как строки.

**Решение.** Строки. Zod проверяет их regex-ом, движок парсит при вычислении.

**Почему.** Одна схема и для YAML, и для собранного JSON, `world.json` читаем глазами, авторам писать проще. Парсинг копеечный при таких объёмах.

**Последствия.** Выражения ограничены видом `quality op int`. Логическое ИЛИ — через два сторилета или приоритеты. Если понадобится сложнее — менять `expressions.ts` в content-schema и парсер в одном месте.
