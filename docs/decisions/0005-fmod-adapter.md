# ADR 0005. Звук: FMOD напрямую через один адаптер

**Статус:** принято, 2026-11-04.

**Контекст.** Нужны дождь, музыка с двумя состояниями и щелчок зажигалки. Звуковой проект собран в FMOD Studio (события `music`, `rain`, `lighter`, у `music` дискретный параметр `MusicState` 0/1).

**Решение.** Рантайм FMOD (`src/fmod/`: js, wasm, типы) и банки из Studio (`src/banks/`) подключаются через Vite: js — ленивым `import()`, wasm и банки — через `?url`. Банки читаются через `fetch` и `loadBankMemory`. Всё это живёт в `apps/miniapp/src/audio.ts`, остальной код видит пять функций. Какая музыка играет, решает контент: `rules.tensionWhen` (условия строками, как в ADR 0001), движок отвечает на это функцией `isTense`.

**Почему.** Как и в ADR 0004: один файл на внешний API, заменить дёшево. Ленивый импорт не тормозит первый экран (3 МБ wasm), а имена файлов получают хеш, поэтому пересобранные банки не залежатся в кэше WebView. Переходы между 0 и 1 делает сам FMOD, в коде их нет.

**Загрузка.** Звук не должен задерживать первый экран, поэтому ~10 МБ (банк 6,8 МБ в Vorbis, wasm 3 МБ) качаются после того, как титул нарисован: `initAudio` ждёт `requestIdleCallback` (в Safari его нет, там таймер), а первый тап запускает загрузку сразу. Банки и wasm идут через Cache API (`belvedere-audio-v1`), а не только через HTTP-кеш WebView: тот общий для всех веб-вью Telegram и первым вытесняет большие файлы, а заголовки хостинга мы не контролируем. Имена файлов с хешем, поэтому запись в кеше всегда актуальна; файлы прошлых сборок удаляются после удачной загрузки. Wasm скачивается нами же параллельно с js-чанком и отдаётся рантайму как `wasmBinary`, так что рантайм не начинает второй запрос после прихода своего js. Запросы идут с `priority: low`, картинки экранов важнее. Хостинг всё равно должен отдавать `/assets/*` с `Cache-Control: public, max-age=31536000, immutable` (это касается и картинок).

**Последствия.** Рантайм и типы обновляются только вместе, банки собираются в Studio той же версии или старше (сейчас 2.03.12). Звук необязателен: любая ошибка загрузки или микшера оставляет игру тихой, автоматических повторов нет, повторить может только переключатель «Звук». Переключатель «Звук» хранится в `localStorage` устройства, не в синхронизируемом сохранении. Первый звук возможен только после касания, поэтому слушатель разблокировки висит на `window` в фазе захвата.
