# Архитектурные ограничения

## Слои и направление зависимостей

```
apps/miniapp, apps/bot  →  packages/ui-kit  →  packages/engine  →  packages/content-schema
packages/validator      →  packages/engine + packages/content-schema
```

Стрелка = «может импортировать». Обратное направление запрещено всегда.
`content/` — данные, их никто не импортирует как код: они загружаются как JSON и валидируются zod.

## Что где живёт

| Пакет | Отвечает за | Не содержит |
|---|---|---|
| content-schema | zod-схемы и типы: качества, сторилеты, фрагменты отчёта, правила мира, манифест ассетов | логики, рантайма |
| engine | `(state, action, world) -> state`, выбор сторилета, условия, эффекты, отчёт, RNG | I/O, DOM, Telegram, `Date.now`, `Math.random`, имён персонажей/этажей/картинок |
| validator | сборка YAML → JSON, правила проверки контента, симуляция прогонов | UI |
| ui-kit | Preact-компоненты, принимающие готовые данные через props | игровой логики, fetch, Telegram |
| apps/miniapp | загрузка контента, Telegram WebApp API, storage, вызов engine, рендер ui-kit | правил игры |
| apps/bot | `/start` → кнопка WebApp | игровой логики |

## Запреты

1. В `packages/engine` нет ни одного литерала из мира: имени, id картинки, номера этажа, названия качества. Всё приходит из `world`.
2. В контенте нет путей к файлам. Картинка = id из `assets/assets.json`.
3. В `apps/*` нет логики, которую можно протестировать без браузера. Если тянет написать `if (state.run.turn >= 16)` в компоненте — это условие в контенте или функция в engine.
4. Рандом только через `rng` из state. `Math.random` запрещён везде, кроме генерации seed в apps.
5. Дублирование кода между apps запрещено: выноси в packages.
6. Схема контента меняется только в content-schema; engine и validator подстраиваются.

## Чек-лист перед изменением

- [ ] Импорты не нарушают направление стрелок?
- [ ] Новая логика живёт в самом нижнем слое, где её можно протестировать?
- [ ] В engine не попало знание о мире или экране?
- [ ] Контент ссылается на картинки по id?
- [ ] Если поменял схему — обновил validator и пример в `storylet-authoring`?
- [ ] `bun test`, `bun run validate`, `bun run typecheck` зелёные?
