# Валидация контента

`bun run validate` = сборка YAML → `build/world.json` (zod-парсинг, падает на ошибке схемы) → правила → симуляция.
Падает с кодом 1 при любой ошибке. Предупреждения не роняют.

## Правила (`packages/validator/src/rules/`)

| Правило | Что ловит | Уровень |
|---|---|---|
| `qualities` | условие или эффект на необъявленное качество, в том числе в `rules.*` (включая `pledgedNightWhen`, `onNightStart`, `migrations`), `when` строк реплик, `report.notes`, `report.progress`, `morning.notes`, `notebook` (страницы, зацепки, `vouchers.names`), слухах, `stairs` и эпилогах концовок; `rules.clock.quality` не объявлено; `rules.start` указывает на несуществующую локацию | error |
| `references` | `goto` выбора или перехвата на несуществующую локацию; `background`/`portrait` нет в `assets.json`; `stairs.location`, `stairs.events`, площадка из `stairs.floors` или `target` зацепки — не локация; замок на этаж, которого нет в `stairs.floors` | error |
| `dead-ends` | локация без сторилетов (error); сторилет, у которого все choices условные (warning; карточка `layout: stairs` не считается: её этажи рисует движок) | error / warning |
| `reachability` | локация, недостижимая из `rules.start` по графу `goto` (условия игнорируются; лестница ведёт на все площадки и к встречам, встреча — на любую площадку) | warning |
| `report-slots` | слот отчёта без фрагментов или без фолбэка (фрагмента без условий) | error |
| `layouts` | `layout: doors` не с тремя дверями (разными `goto`; выборы с одним `goto` — варианты одной двери) или дверь без `goto`; `layout: pledge` без `memories` в мире или без безусловного `endNight`-выбора; `layout: stairs` без `stairs` в мире или вне `stairs.location`; `floors` у сторилета не из `stairs.events` | error |
| `placeholders` | `{…}` в тексте и репликах сторилета, подписи выбора, `outcome`, `reply`, фрагмента, пометки отчёта, страницы блокнота, зацепки, слуха или карточки улики, не являющийся объявленным качеством (в `report.progress` разрешены ещё `{leads_done}` и `{leads_total}`) | error |
| `lines` | `who` реплики нет в `speakers`; у выбора нет ни `say`, ни `do`, ни `text` (error). Лимиты авторов (warning): рассказчик больше 25 слов, персонаж больше 30, внутренний голос больше 15; больше 4 реплик до выбора или 3 в `reply`; `say`/`do` длиннее 8 слов; «много выборов» — карточка с репликами, где больше 8 выборов и хотя бы один оставляет на месте | error / warning |
| `rumors` | повторный `id` слуха; `rumor.<id>` не объявлено; `rules.firstNightRumor` не из `rumors.yaml` | error |
| `memories` | пара с повторным `id`, необъявленным, одинаковым или повторно использованным флагом, `returnWhen` на необъявленное качество; мир с парами без `pledged.*`, `returned.*`, `returned_tonight`, `memories_returned` | error |
| `notebook` | повторный `id` страницы или зацепки; `when` страницы, `life.footer`, `when`/`done` зацепки, `when` и `names` страницы поручителей на run-качество (закрылись бы на следующую ночь); плейсхолдер в `life.states` кроме `{label_fake}`/`{label_real}` | error |
| `self-exclusion` | выбор без `goto`/`endNight` ломает `when` своей карточки, а другие остающиеся выборы нет: после него карточка сменится посреди сцены и соседние вопросы пропадут. Не срабатывает, если флаг ставят все остающиеся выборы (карточка на один показ) или у карточки `intro: true` | warning |
| `planned` | условие на качество, которое ничего не ставит (ни эффект, ни правило, ни движок) и у которого default 0. Обычно контент будущих этажей | warning |
| `evidence` | повторный `id` карточки; `flag` на необъявленное качество; `image` нет в `assets.json`; мир с уликами без `found.*` | error |
| `endings` | `ending` выбора не из `endings.yaml`; `ending` вместе с `endNight`; повторный id концовки; картинки нет в `assets.json`; `endings.*` или `ending_night` не объявлено; `opening_slot`/`litany_slot` не из слотов отчёта | error |

Тупики по состоянию (нет подходящего сторилета, нет доступных выборов) ловит симуляция, а не статическое правило: условия вида `seen.x == 0` / `seen.x == 1` или набор `floor == 1..4` дополняют друг друга, и статически это не видно. Поэтому «все выборы условные» — warning, а `stuck` в симуляции — error.

Ожидаемые предупреждения на полном мире (этажи 1–12, подвал, тринадцатый): только «много выборов» у `eddie_laundry` (10) и `sloan_office` (9) — одновременно там видно 3–5, остальные закрыты условиями; `planned` быть не должно. Случайный игрок за 200 ночей не доходит до концовок (`by ending: 0`, в «never shown» карточки Владельца, тринадцатого, финала): до них доходят направленные маршруты кампании в `belvedere-night.test.ts`, автор проверял 44 000 ночей.

Каждое правило — функция `(world, assets) => Issue[]`, `Issue = { level, where, message }`.

## Добавить правило

1. Файл `rules/<name>.ts`, экспорт `check(world, assets): Issue[]`.
2. Добавь в список в `rules/index.ts`.
3. Тест в `packages/validator/test/<name>.test.ts` на мини-мире из трёх сторилетов: один проходит, один ломает.
4. Строка в таблицу выше.

## Симуляция

`simulate.ts` прогоняет N ночей (по умолчанию 200) со случайным выбором через engine: экраны `outcome` пролистываются, на `pledge`-экране случайно выбирается воспоминание или обычный выбор, на лестнице — любой открытый этаж или возврат на площадку; слух каждой ночи движок тянет сам; профиль тянется через 5 ночей подряд, потом сбрасывается. Печатает:

```
simulated 200 nights
  ended by memory pledge: 120, by endNight choice: 80, by ending: 0, stuck: 0, errors: 0
  turns per night: min 1, avg 5.7, max 17
  storylets never shown (6): lobby_late, pledge_caught, ...
  choices never taken (15): lobby_hub#1, ...
```

Как читать:
- `stuck > 0` или `errors > 0` — состояние без доступных выборов или исключение движка. CLI выходит с кодом 1.
- `never shown` / `never taken` — сторилет или выбор недостижим для случайного игрока. Либо условия слишком строгие, либо путь длинный. Решай по смыслу: случайный игрок часто уходит из башни рано.
- `turns per night` — случайный игрок выбирает «уйти» так же охотно, как остальное, поэтому среднее ниже, чем у живого игрока. `max` может быть чуть больше лимита перехвата: выбор с собственным `turn += 1` плюс `onChoice` перескакивает через 16.

Запуск с другими параметрами: `bun run packages/validator/src/cli.ts <world.json> <assets.json> --nights 1000 --seed 7`.
